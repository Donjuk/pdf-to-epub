# PDF → EPUB Converter (Xteink X3)

Local tool that converts **PDF → EPUB** optimized for the **Xteink X3** (3.7" e-reader, 528×792, 259 PPI).

The X3 handles **EPUB** and **TXT** well. PDF is often poor or unsupported on firmware — a clean reflowable EPUB is the better fit for that small screen.

## What the optimization does

- Extracts text from the PDF and rebuilds chapters (when titles are detected)
- Lean CSS (no embedded fonts — the X3 often mishandles them)
- Images resized (~480 px), grayscale, light JPEG
- Simple EPUB2, compatible with basic e-ink readers

## Requirements

- Python 3.10+

```bash
cd "pdf-to-epub"
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

## CLI

```bash
python cli.py book.pdf
python cli.py book.pdf -o out/book.epub
python cli.py book.pdf --title "My Book" --author "Author"
python cli.py book.pdf --no-images
```

## Web UI

```bash
python web.py
```

Open [http://127.0.0.1:5000](http://127.0.0.1:5000), upload a PDF, download the EPUB.

The UI supports **English**, **Portuguese**, and **Spanish** (language switcher in the top-right).

## On the device

1. Copy the `.epub` to the **microSD** (Xteink folder), **or**
2. Send it through the official app (Wi‑Fi / QR)

## Limitations

| PDF type | Result |
|---|---|
| Selectable text | Good |
| Scanned (image-only) | Needs OCR first (e.g. Adobe, OCRmyPDF) |
| Complex layout (columns, magazines) | May come out messy — try `--no-images` and review |

## Target specs (X3)

| Field | Value |
|---|---|
| Display | 3.7" E Ink |
| Resolution | 528 × 792 |
| Density | 259 PPI |
| Formats | EPUB, TXT (+ JPG/BMP) |
